# Diseño del MVP

La interfaz implementada usa verde profundo, crema, navegación lateral y tarjetas para membresía, horarios y consultas. La captura `demo.png` muestra datos ficticios y el estado visual del demo del 10 de noviembre de 2026.

## Material incluido

- `concepts/conceptos.png`: comparación de tres propuestas de símbolo.
- `concepts/abrazo.svg`, `concepts/cerca.svg`, `concepts/enlace.svg`: originales editables de los conceptos.
- `concepts/conceptos.svg`: hoja de presentación editable.
- `demo.png`: captura del panel implementado.

Los tres símbolos son propuestas pendientes de elección, no un logo final aprobado. La interfaz conserva su identificador provisional. El sistema completo de marca y sus variantes quedan pendientes de esa elección.

La referencia visual se generó con Higgsfield, GPT Image 2.6. El diseño implementado es HTML/CSS y JavaScript funcional; no depende del servicio de generación para ejecutarse.

## Ejecutar la demostración

Desde la raíz: `npm ci` y `npm run demo`. Abra `http://localhost:3001` para cambiar entre paciente, médico y administrador con cuentas ficticias. El demo está limitado al equipo local.
